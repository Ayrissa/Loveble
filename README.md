# Loveble — языки любви и проявление привязанности для SillyTavern

Расширение создаёт **записи лорбука** о том, как персонаж (юзер) любит, проявляет привязанность и строит отношения. Записи короткие, плотные и работают как карточка поведения.

## Разделы

| Раздел | Что внутри |
|---|---|
| Язык любви | основной и второй язык, как проявляет и что хочет получать, что ранит, примеры |
| Открытость чувств | от подавляет и избегает до тактильного и легкомысленного, признания, уязвимость |
| Физическое проявление | поцелуи, объятия, прикосновения, отношение к ним, на людях и наедине |
| Сексуальность (18+) | ориентация, опыт, подход, инициатива, предпочтения, границы, стиль, близость после |
| Построение отношений | нежно, грубо, токсично, здорово, забота, внимание, ревность, конфликты, границы |
| Расставания | громко или тихо, кто уходит, что после, возвращается ли, обиды |

## Как устроено

1. На странице **Extensions** найди панель Loveble и нажми «Открыть Loveble» (или команда `/loveble`).
2. Выбери, для кого: **Персонаж** или **Юзер**. Имя подставится само (текущий персонаж или имя персоны). Прозвища пиши через запятую: они станут ключами.
3. Опиши человека или нажми «Подтянуть из карточки» (описание берётся из карточки или из персоны). Если оставить поле пустым, описание карточки подтянется само.
4. Выбери разделы плитками. «Сексуальность» открывается только после галочки «Совершеннолетний (18+)».
5. Нажми «Сгенерировать». Любую запись можно править руками, менять её ключи и перегенерировать отдельно. Если модель обрезала раздел, он дописывается автоматически.
6. Нажми «Создать лорбук»: записи сохранятся в лорбук `Loveble - Имя`. Повторное сохранение обновляет записи, а не дублирует их. Если дать разным людям одинаковое название лорбука, они окажутся в одном.

Дальше подключи лорбук в Таверне как обычно: World Info → выбрать лорбук (глобально или для персонажа).

## Ключи и срабатывание

- Язык ключей: английский, русский или оба.
- Режим срабатывания: **имя + тема** (по умолчанию, избирательные ключи), только тема, только имя или всегда включена.
- Позиция в промпте: перед или после описания персонажа.
- У каждой записи ключи можно редактировать прямо в окне.

## Прочее

- Темы: Румянец, Шалфей, Небо, Лагуна (тёмная), Авто (цвета Таверны).
- Свобода додумывания: строго, баланс, смело. Размер записи задаётся в настройках.
- Экспорт лорбука в JSON и копирование текста.

## Установка

В SillyTavern: **Extensions → Install extension** и вставь ссылку:

```
https://github.com/Ayrissa/Loveble
```
